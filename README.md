# economic-growth-trade-analysis

Econometrics project on international trade and economic growth using the World Development Indicators (WDI) dataset.

## Contents

- `trade_growth_wdi_analysis.ipynb`: final Python notebook
- `trade_growth_wdi_analysis_R.Rmd`: R notebook version
- `trade_growth_wdi_analysis_R.R`: executable R script
- `trade_growth_clean_panel.csv`: cleaned panel used in the analysis
- `trade_growth_clean_panel_professor.csv`: extended cleaned panel
- `r_outputs/`: exported R tables and figures

## Topic

This project studies the relationship between trade openness and GDP growth with macroeconomic controls, diagnostics, robustness checks, and subgroup analysis.
